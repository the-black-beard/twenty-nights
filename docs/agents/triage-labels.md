# Triage labels

| Role | Tracker label | Meaning |
|---|---|---|
| needs-triage | needs-triage | Maintainer evaluates the issue |
| needs-info | needs-info | Waiting for information from the reporter |
| ready-for-agent | ready-for-agent | Fully specified for a bounded worker |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Use triage for incoming raw requests, not tickets already produced by `/to-tickets`. Check existing tracker labels before creating any; label creation needs the authorized external-write scope.
