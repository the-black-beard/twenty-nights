# One self-contained file, and no external assets ever

The whole game is a single `index.html` with no libraries, no build step needed
to play it, and not one external request — images, fonts and sounds are all
generated in code or embedded.

It is published as a claude.ai artifact, where the host blocks all network
requests, so anything fetched at runtime simply fails. The same constraint turns
out to be the project's best feature: the file can be AirDropped or emailed to a
friend and it runs with no account, no server and no internet.

**Consequences**: graphics are drawn with Canvas 2D, sound is synthesised with
WebAudio, and the icon is generated by `tools/makeicon.js` rather than designed
in an image editor. Feedback cannot be submitted, only copied to the clipboard.
Reach for an asset file and the game stops being sendable.
