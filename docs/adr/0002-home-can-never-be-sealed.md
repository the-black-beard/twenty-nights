# Home can never be sealed off

A player may not complete a wall that leaves no Route from any Portal to Home.
Placement is refused at the moment it would seal.

The first playable version allowed it, and it broke the game completely: build a
closed ring, stand still, win. Every subsequent mechanic — the Route, the Light
Maze, Chewers, Fort Tier — assumes a Route exists and has a length worth
manipulating. Sealing makes all of it meaningless at once.

**Consequences**: this is the single invariant the design rests on, and it is
also the thing players most often try to do, because sealing a wall is the
obvious move. Expect the refusal to feel frustrating; that frustration is a
signal to make the refusal *legible* (a gate you place deliberately, say), never
to relax the invariant. Light also obeys this: a map carpeted in torches is
still crossable.
