# Threads

Work on Twenty Nights is split into threads — one conversation each, named so
that the list sorts into the order the work happens in.

## The prefix

```
TN-<phase><number> · <short name>
```

`TN` for the project, a letter for the phase, a number within it. Alphabetical
order is chronological order, so a sorted list of sessions reads as a plan.

| Phase | What it covers |
|-------|----------------|
| **A** | Foundation — repo, docs, tooling, CI |
| **B** | Finalise v1 — the current feedback round, shipped to friends |
| **C** | Prototypes — throwaway code answering one design question |
| **D** | The Nether — the maze level and the hammer |
| **E** | The Swarm — the finale and the ending |

## What TN-A2 landed

The repo is public at `the-black-beard/twenty-nights` and the game is live at
<https://the-black-beard.github.io/twenty-nights/> — no account, no install,
nothing to download. That URL replaces artifact links as how the game is
shared. Pages rebuilds `dist/` from `index.html` on every push to `main`, and
the assertions and the playthrough run *before* the build, so a push that
breaks the game fails the deploy and leaves the last good copy serving.

Public was chosen deliberately; `threads/TN-A2.md` records why.

**The near-miss worth remembering.** The first attempt at a pseudonymous
identity set `user.email` to the noreply address and left `user.name` as the
real full name, so every commit carried it in a field no file-content check
ever looks at. A grep of the tracked files said clean; the commits said
otherwise. It was caught before the first push, the history was rebuilt with
the codename in every tree and message, and nothing reached the remote with a
real name in it. Check metadata, not just content.

**Still open, deliberately.** The three `claude/*` worktree branches point at
pre-rewrite commits that still carry the old name and the real author. They
were never pushed, and the remote carries `main` only — but they should be
cleared locally once the work in them has landed.
`claude/great-blackwell-49713a` holds C1's uncommitted findings; save those
first.

Two things from TN-A1 still worth knowing: the repo-local git identity is
`The Black Beard <the-black-beard@users.noreply.github.com>`, deliberately not
the work address configured globally; and everything under `assets/`, `dist/`
and `Twenty Nights.html` is generated by `node tools/build.js` and untracked,
which was verified by wiping and rebuilding them byte-for-byte.

## Rules

- **One thread, one phase.** Grilling, spec and tickets stay in a single
  unbroken conversation so they build on the same thinking. Each implementation
  ticket then starts fresh from the ticket.
- **A thread ends when its output is in the repo.** If something is worth
  carrying to the next thread, it belongs in `CONTEXT.md`, an ADR, or a ticket —
  not in conversation history.
- **Prototypes get their own directory**, outside this repo, and hand their
  findings back as a written file in `docs/prototypes/`.

## Branches and tags

| Pattern | Meaning |
|---------|---------|
| `main` | What friends are playing. Only merged after someone has actually played it. |
| `try/<idea>` | One design variant, built to be played and compared against another. |
| `tn-<phase><n>/<slug>` | Ticket work. |
| `archive/<idea>` *(tag)* | A variant that lost. Kept forever, costs nothing, out of the way. |

A rejected idea is tagged, never deleted. When two variants are in play, publish
each as its own artifact and let ig-b-dynamix play both before anything is merged.
